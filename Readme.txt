DecUbiSnd is a program to decode the audio streams found in many UbiSoft games. Run DecUbiSnd without any arguments to get a list of command line switches. The Examples directory contains a few examples of usage in the form of batch files.

Feel free to use the source code in your project. If you do, credit is appreciated but not required.
